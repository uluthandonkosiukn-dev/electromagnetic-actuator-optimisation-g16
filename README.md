# Electromagnetic Actuator Optimisation

## Project Overview

This repository contains the MATLAB code and optimisation results for the electromagnetic actuator design project. The MATLAB program was developed to automate the magnetic-circuit calculations and evaluate different actuator configurations.

The optimisation investigates two main design variables:

* Number of laminations: 1–36
* Number of coil turns: 1500–3000

The main optimisation objective is to maximise the calculated force-to-weight ratio.

## Methodology

The MATLAB program calculates the electrical and magnetic characteristics of each design, including:

1. Coil resistance
2. Coil current
3. Applied magnetomotive force (MMF)
4. Magnetic flux density
5. Magnetic field strength using the B-H relationship
6. Magnetic reluctance
7. Rate of change of reluctance
8. Magnetic force
9. Actuator mass and weight
10. Force-to-weight ratio

The magnetic field strength is obtained using the fitted B-H relationship:

$$
H=\frac{142.248B}{1.626-B}
$$

An iterative calculation is used to determine the flux density until the calculated magnetic MMF converges within the specified tolerance.

The program then evaluates the different combinations of laminations and coil turns and identifies the design with the maximum force-to-weight ratio.

## Optimisation Result

The selected optimum design obtained from the MATLAB optimisation was:

| Parameter             |         Result |
| --------------------- | -------------: |
| Number of laminations |         **36** |
| Number of turns       |       **1500** |
| Resistance            |  **27.1036 Ω** |
| Current               |   **0.8855 A** |
| Applied MMF           | **1328.24 At** |
| B at 2.0 mm gap       |   **0.5503 T** |
| B at 2.1 mm gap       |   **0.5245 T** |
| Magnetic force        |  **58.2620 N** |
| Mass                  |  **5.0738 kg** |
| Weight                |  **49.7744 N** |
| Force-to-weight ratio |   **1.170522** |

The force is reported as a magnitude above; the MATLAB calculation gives a negative sign according to the defined force direction.
